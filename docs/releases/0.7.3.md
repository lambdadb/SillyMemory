# SillyMemory 0.7.3 — experimental pre-release

Prepared release boundary: **2026-10-28**. Main promotion, tags and GitHub Release
publication remain separate actions.

## Changes from 0.7.2

Update the transitive Zod lockfile resolution from `4.6.5` to `4.6.7`, outside the
affected range of [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5).
The pinned LambdaDB SDK remains `0.9.0`. The shipped browser bundle and extension
runtime are byte-identical to 0.7.2; Git installations use that bundle, so the
lockfile update does not change installed runtime behavior.

The README now links the existing 2:05 product walkthrough. It demonstrates
memory recall, source inspection, input token comparison, checkpoints and chat
branches with synthetic dialogue and scripted retrieval/replies. Its token
figures are host input estimates, not billing or typical savings.

Supported host: SillyTavern 1.19.0 at
`06bde939fb1e9c4c8d8641d810f0a916b5bce127`, with Chromium.
Retrieval defaults, credentials, storage formats and native reply/streaming
behavior are unchanged.

## Install, update and rollback

Install the repository URL with an empty branch field to follow `main`.
Use Extensions → Manage extensions → SillyMemory → Update, then reload.
No npm installation, build step, storage migration or credential re-entry is
introduced by this patch. Main can deliver the update only after promotion;
release preparation alone does not publish it.

Preserve native chats and backups before updating. For rollback, disable memory
and pin published `v0.7.2` following [the release procedure](../../RELEASING.md#user-updates-and-rollback).
Code rollback does not undo remote writes or restore deleted data.

## Validation and limits

See [the acceptance record](0.7.3-validation.md) for measured checks and limits.
This preparation makes no new answer-quality, live-provider compatibility or
server-rollout claim. Other browsers, host versions, group/tool conversations
and concurrent multi-device writers remain outside the supported scope.
