## Commands and reproduction

Use the measured producer revision in clean disposable worktrees. **Use a separate
producer worktree and a separate pinned host for each browser/recovery run.**
`SM_ARTIFACT_TAG` names their JSON reports and fault images, but not the generic
`artifacts/setup.png` and `artifacts/settings.png`; a new tag alone does not prevent
screenshot replacement. Never rerun either suite in a producer containing earlier
receipts. Archive that worktree's artifacts before retiring it.

Install locked dependencies (`npm ci`) in each producer and pinned host. Keep the
installation host free of global extension symlinks. The browser harness links
its own producer into its host; do not share that host across producer worktrees.
All installation tags and delivery output paths must also be new.

```sh
npm ci
npm run check:sdk
npm run check:release
npm run check
for file in scripts/*.mjs tests/*.js; do node --check "$file" || exit; done
npm test

ST_SOURCE=/path/to/pinned/host ST_INSTALL_PORT=18179 \
SM_ARTIFACT_TAG=release050-main-unique npm run test:install

ST_SOURCE=/path/to/pinned/host ST_INSTALL_PORT=18179 \
SM_INSTALL_BRANCH=develop \
SM_UPDATE_FROM=320c17e9d94fb7dfed7ed53a5be0df96c4f75065 \
SM_ARTIFACT_TAG=release050-update-unique npm run test:install

# A new producer worktree and pinned host, containing no earlier receipts.
cd /path/to/fresh/browser-producer
ST_SOURCE=/path/to/browser-host ST_TEST_PORT=18176 \
SM_ARTIFACT_TAG=release050-unique npm run test:browser
# Delivery uses that same producer/host link and an explicitly unique output path.
ST_SOURCE=/path/to/browser-host ST_DELIVERY_PORT=18177 \
node scripts/prompt-delivery-smoke.mjs artifacts/prompt-delivery-release050-unique.json

# A different new producer worktree and host: generic screenshots cannot collide.
cd /path/to/fresh/recovery-producer
ST_SOURCE=/path/to/recovery-host ST_TEST_PORT=18178 \
SM_ARTIFACT_TAG=release050-unique npm run test:recovery
```

The measured candidate branch was removed after PR #90 merged. The example uses
