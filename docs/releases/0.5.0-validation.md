# 0.5.0 installation and host acceptance

## Decision and scope

**Installation and current-host acceptance pass (2026-10-20).** Prepare 0.5.0 as
an experimental candidate independently of PR #89. The preparation changes version
metadata and documentation only; product runtime, SDK, settings, defaults, harnesses
and tests match `cbd27ab470e67af105b2bd56fd3f642c6702cf17` (through PR #88).
No paid provider calls, new answer-quality evaluation or storage migration was run.

The candidate remains **Unreleased**. A reviewed date, develop-to-main merge commit,
main CI, tag and GitHub pre-release publication remain separate authorized steps.
Public main still serves 0.4.0. Additional quality experiments are not needed to
complete this bounded installation/host acceptance gate.

## Commands and reproduction

Run from the measured producer. Use separate disposable pinned host checkouts or
run installation before the browser harness adds its global extension symlink.
All artifact tags/output paths must be unique; preserve earlier receipts.

```sh
npm ci
npm run check:sdk
npm run check:release
npm run check
for file in scripts/*.mjs tests/*.js; do node --check "$file" || exit; done
npm test

ST_SOURCE=/path/to/pinned/host ST_INSTALL_PORT=18179 \
SM_ARTIFACT_TAG=release050-main-unique npm run test:install

ST_SOURCE=/path/to/pinned/host ST_INSTALL_PORT=18179 \
SM_INSTALL_BRANCH=chore/release-050 \
SM_UPDATE_FROM=320c17e9d94fb7dfed7ed53a5be0df96c4f75065 \
SM_ARTIFACT_TAG=release050-update-unique npm run test:install

ST_SOURCE=/path/to/pinned/host ST_TEST_PORT=18176 \
SM_ARTIFACT_TAG=release050-unique npm run test:browser
ST_SOURCE=/path/to/pinned/host ST_TEST_PORT=18178 \
SM_ARTIFACT_TAG=release050-unique npm run test:recovery
ST_SOURCE=/path/to/pinned/host ST_DELIVERY_PORT=18177 \
node scripts/prompt-delivery-smoke.mjs artifacts/prompt-delivery-release050-unique.json
```

The candidate branch must still exist on GitHub for native installation. Once
removed, use an existing branch and record its exact remote SHA; that is a new run,
not historical reproduction. The original producer and receipts remain archived.

An offline `checkPromotion` call confirms 0.5.0 advances public 0.4.0 and does not
reuse a fetched tag. A separate assertion confirms `requireDate` rejects Unreleased.
The full `--base-ref origin/main` publication check is deliberately not passed at
this stage because it requires the agreed release date. Recheck the exact eventual
promotion commit and any intervening runtime changes before main is changed.
