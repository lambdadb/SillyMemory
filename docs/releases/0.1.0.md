# SillyMemory 0.1.0 (experimental)

Long-term memory for SillyTavern. **Powered by LambdaDB.**

SillyMemory keeps recent messages intact and retrieves relevant passages from
older conversation under a memory token budget. This first experimental release
supports individual character chats, including synchronization after generation,
edits, swipes, deletion and reload, with separate character/chat/branch scopes.
The settings panel shows injected memory and synchronization progress, and offers
controls to disable memory or delete the installation's owned remote memory.

## Install and connect

1. Use **SillyTavern 1.19.0**. Other host versions are unverified.
2. In **Extensions → Install extension**, enter
   `https://github.com/lambdadb/SillyMemory` and leave the branch/tag field empty
   to follow main. No extension build step or server plugin is needed.
3. Set `enableCorsProxy: true` in SillyTavern's `config.yaml` and restart the host.
4. Open the SillyMemory settings, enter your LambdaDB endpoint, project and API
   key, and run the synthetic upsert/query/delete test. After it passes, create
   the memory collection and enable memory in a character chat.

See the [installation guide](https://github.com/lambdadb/SillyMemory/blob/main/README.md#install)
for requirements and detailed setup. Keys are held only in browser memory;
reload requires key re-entry and re-enabling memory. Source passages and search
queries are sent through the host proxy to LambdaDB and its managed embedding
provider. LambdaDB and embedding usage incur costs.

## Limits and data cleanup

Use one active extension tab per account/browser profile. Group chats, files,
tool messages, Data Bank, World Info and other prompt-rewriting memory extensions
are outside this release's scope. Disable built-in Vector Storage chat
vectorization when using SillyMemory. Cross-device concurrent editing and
long-duration reliability are unverified.

Deleting or renaming chats, clearing browser storage, or uninstalling the
extension does not clean up every remote scope. Use **Delete all owned remote
memory** and clear any pending test collection before uninstalling. Local chats
remain intact. Remote deletion does not establish erasure from provider backups.

## Validation

Recorded checks include 68 unit tests on Node 20/24, 17 real Git URL installation
and candidate-update assertions, and 188 real-host/emulator checks including two
controlled host-crash recoveries. A held-out synthetic evaluation retrieved the
target and returned its expected code in 12/12 memory-on cases, with 11/12 strict
code-only answers. These are bounded synthetic results, not a general recall or
availability guarantee. Installation checks cover unreleased commits, not an
upgrade between published versions.

See the [validation record](https://github.com/lambdadb/SillyMemory/blob/main/docs/validation.md)
for exact source identities and remaining checks. Updates are manual through
SillyTavern's extension manager. Disable memory first if a problem occurs.
