# SillyMemory 0.7.2 — experimental pre-release

Prepared release boundary: **2026-10-26**. Main promotion, tags and GitHub Release
publication remain separate actions.

## Changes from 0.7.1

Update the LambdaDB JavaScript SDK from development version
`0.8.1-dev.38730896042001` to stable `0.9.0`, including the shipped browser bundle.
Retrieval still uses 200 rerank candidates and returns up to 50 passages.
Credential scope, storage formats, recent-history boundaries and native streaming
remain unchanged. No Python SDK is introduced.

Supported host: SillyTavern 1.19.0 at
`06bde939fb1e9c4c8d8641d810f0a916b5bce127`, with Chromium.

## Install, update and rollback

Install the repository URL with an empty branch field to follow `main`.
Use Extensions → Manage extensions → SillyMemory → Update, then reload.
The SDK bundle ships in Git; no npm installation or compilation is required.
No storage migration or credential re-entry is introduced by this patch.

Preserve native chats and backups before updating. For rollback, disable memory
and pin published `v0.7.1` following [the release procedure](../../RELEASING.md#user-updates-and-rollback).
Code rollback does not undo remote writes or restore deleted data.

## Validation and limits

See [the acceptance record](0.7.2-validation.md) for measured checks and limits.
This update makes no new answer-quality or server-rollout claim. Other browsers,
host versions, group/tool chats and concurrent multi-device writers remain outside
the supported scope. No live provider evaluation was added.
