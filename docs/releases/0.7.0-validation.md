## Executed commands

Run from the clean preparation worktree after `npm ci`. The isolated host has no
global SillyMemory installation or symlink. The candidate branch must exist on
GitHub; every artifact tag must be new.

```sh
npm test
npm run check
npm run check:sdk
npm run check:release -- --require-date
npm run check:release -- --base-ref origin/main
npm run check:release -- --tag v0.7.0
for file in scripts/*.mjs tests/*.js benchmark/*/*.mjs; do node --check "$file" || exit; done
python3 -m unittest discover -s tests -p 'test_*.py'

ST_SOURCE=/path/to/isolated/pinned/SillyTavern ST_INSTALL_PORT=18179 \
SM_INSTALL_BRANCH=chore/release-070 \
SM_UPDATE_FROM=cae42d58d955a1688ced3075ad05227923f36772 \
SM_ARTIFACT_TAG=release070-candidate-update npm run test:install
```

The tag-name check creates no tag. No main merge, tag or GitHub Release is
established by this preparation. After preparation merges, open develop → main
and use a merge commit after maintainer approval. Verify main/tree/CI before
separately authorized tag and experimental pre-release publication.
