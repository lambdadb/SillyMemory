## Reproduction and retained evidence

```sh
ST_SOURCE=/path/to/isolated/pinned/SillyTavern \
SM_INSTALL_BRANCH=develop \
SM_UPDATE_FROM=b262dc5dac942a50a9fd247974d748060b89761b \
SM_ARTIFACT_TAG=install-update-unique npm run test:install
```

The branch must exist on GitHub. Use the preparation branch for candidate-specific
validation; the report records its exact remote SHA. Omit `SM_UPDATE_FROM` for
fresh installation only and omit `SM_INSTALL_BRANCH` to test public main.
The runner verifies the pinned host and rejects global extension symlinks.
Reports/screenshots and the measured producer are retained locally under ignored
artifacts; see the [evidence index](../evidence-retention.md). They are not fresh-clone
CI dependencies. Existing live-service/streaming, failure and checkpoint evidence
remains separately linked; no paid acceptance was rerun for this installation task.
