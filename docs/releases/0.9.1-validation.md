# 0.9.1 installation and update acceptance

## Scope

Prepare develop `b275156` (`fix: report requested analyzers for a just-created
story collection (#144)`) as experimental 0.9.1, dated **2026-11-06** under the
maintainer's authorization of the full release sequence. The candidate carries
the fix for the false "indexed with: standard" notice on a just-created story
collection and the bounded live analyzer check (#144), merged to `develop` on
2026-11-06 after the publication of 0.9.0. Preparation changes version
metadata, the changelog title and compatibility section, release notes and
RELEASING only; product runtime, dependencies and the shipped SDK bundle are
those of that develop revision.

The defect was found by the live check itself: LambdaDB's collection-creation
(201) body carries no `indexConfigs`, which 0.9.0 read as the service default
`standard`. The fix reports the requested analyzers on the create path; the
read path is unchanged. The unit-test fixture for the 201 body now mirrors the
real response.
