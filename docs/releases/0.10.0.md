# SillyMemory 0.10.0 — experimental pre-release

Prepared release boundary dated **2026-11-11**. Preparation, main promotion,
version tags and GitHub Release publication are separate steps. Confirm
publication in [GitHub Releases](https://github.com/lambdadb/SillyMemory/releases).

Supported host: SillyTavern 1.19.0 at
`06bde939fb1e9c4c8d8641d810f0a916b5bce127`, with Chromium.
Other host versions and browsers remain unverified.

## Changes from 0.9.1

- **Private memory** (#150, decision evidence in #149). An opt-in setting for
  newly created stories: your browser embeds older messages and queries
  through an OpenAI-compatible embedding endpoint you choose, such as local
  Ollama or OpenAI. LambdaDB stores only vectors and metadata; raw text is not
  sent to or stored in LambdaDB. Recalled passages are restored from the open
  chat. Search is dense vector search without reranking. Presets: Ollama
  `qwen3-embedding:0.6b`, Ollama `embeddinggemma` and OpenAI
  `text-embedding-3-small`; other models are allowed and labelled as not
  validated. The switch unlocks after **Test and save** succeeds. Turning it on
  pauses existing standard stories until **Rebuild story memory**; turning it
  off keeps private stories working while their embedding model, prefixes and
  dimension match the tested settings, with an optional rebuild to standard
  memory. Speaker names, timestamps, message numbers and a revision digest are
  still stored as metadata. See [Private memory](../private-memory.md).
- **Group chats** (#148). Memory can be turned on in a SillyTavern group chat
  with the same storage, retrieval and failure handling as a character chat.
  Each group chat starts its own story; checkpoints and branches reuse it.
  Each responding member's reply searches memory with the latest user
  message. A memory preparation failure stops the whole round. The recent
  window now keeps the current turn whole; ordinary alternating chats keep the
  previous boundary. Swipe excludes only the swiped reply. See
  [group chats](../group-chat.md).
- **Prompt-only regex scripts apply to memory** (#151). Regex scripts set to
  **Alter Outgoing Prompt** now apply before saving and searching, at the
  message's depth, so text they hide (such as tracker blocks) no longer
  returns through recalled memory. Scripts that use macros are not applied to
  memory; a group chat uses global and preset scripts only.
- **Documentation** (#152). README recovery and update notes match the
  observed behavior.

## Installation, update and rollback

Install the repository URL with an empty branch field to follow public main.
Reviewers can enter `release/0.10.0` or `develop` in the branch field in an
isolated profile before main promotion. Update through Extensions → Manage
extensions → SillyMemory → Update, then reload. Update follows the installed
Git branch, not the newest tag/Release. Automatic updates remain disabled; no
build step or server restart is needed.

**Updating from 0.9.x:** there is no settings or data migration. Private memory
is off by default; existing standard stories, each chat's saved on/off choice,
the saved key and saved memory are unaffected unless you turn it on. If you use
**Alter Outgoing Prompt** regex scripts, the first sync after updating saves the
affected older messages again. The extension manager shows version 0.10.0.

To roll back, disable memory and pin published `v0.9.1` using the
[release procedure](../../RELEASING.md#user-updates-and-rollback). 0.9.1 does
not know private stories (collections without a `text` field) and rollback with
them was not tested: before rolling back, rebuild them to standard memory with
Private memory off, or turn memory off in those chats. 0.9.1 does not support
group chats, and it saves the original text of messages that **Alter Outgoing
Prompt** scripts change, so its next sync may save those messages again.

## Acceptance and limits

See [0.10.0 acceptance](0.10.0-validation.md) for the inherited evidence of
the merged PRs, the maintainer's manual test, the installation/update and
browser acceptance and the checks that were not performed.

Known limits of this release:

- Private memory quality was validated on English LongMemEval-S only; no
  multilingual quality claim is made. File and image uploads are not supported
  in Private memory. The OpenAI preset was not exercised against the live API.
- Group-chat answer quality was not evaluated. Group Auto Mode without user
  input keeps every reply since the last user message in the prompt; with
  **Stop on missing context** on, a long run stops and Auto Mode turns off
  until a message is sent. After SillyTavern's own **Stop**, Auto Mode rounds
  generate nothing until a message is sent (a SillyTavern limitation).
- Memory uses ordinary-reply depth for regex scripts also during **Continue**
  and **Swipe**, so a script's depth boundary can differ by one there.
- Concurrent multi-device writers and non-Chromium browsers remain
  unverified. Previewed memory, prompt verification and token estimates do not
  establish answer correctness or provider receipt.
