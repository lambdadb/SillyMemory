Advanced Limits, connection test and deleting memory

Memory limits

The default is 4,096 tokens, capped at one quarter of SillyTavern's context size. Saved custom budgets are preserved.

Stop the reply if SillyTavern's final prompt leaves out or changes the added memory or recent messages. Turn off to continue with a warning.

Connection test

Connects directly to LambdaDB from this browser. No SillyTavern proxy setting or restart is needed.

Delete memory

Delete all memory removes the memory of every story and branch. Your local chats are kept. Deleting a chat in SillyTavern does not delete its memory. To delete one chat's memory, open This chat's memory in that chat's Memory panel.

How memory works

Older messages in a chat are saved as memory, while the latest five messages always stay in the prompt as they are. When you send a message, SillyMemory searches that memory and adds related passages to the prompt. Each story keeps its own memory, and a branch starts from the memory of the chat it came from.

The model answers as usual; SillyMemory only adds memory and short guidance, and never forces a reply format.

Files, tool messages, Data Bank and World Info are not saved. Renaming a chat keeps its memory. Do not use the same memory from two devices at the same time.
