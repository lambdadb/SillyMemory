SillyMemory

Long-term memory for SillyTavern.
Powered by LambdaDB

Chat excerpts and retrieval queries are sent through your SillyTavern server to LambdaDB and its embedding provider. A LambdaDB account and inference usage are required. Disable pauses use; it does not delete remote data.

Enable enableCorsProxy: true in SillyTavern config.yaml and restart before testing.

Group chats, files, tool messages, Data Bank, and World Info are excluded. Turn off other chat vectorization extensions. The first version supports one active SillyMemory tab per browser profile.
