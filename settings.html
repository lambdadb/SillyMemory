SillyMemory

Long-term memory for SillyTavern.
Powered by LambdaDB

Chat excerpts and retrieval queries are sent directly from this browser to LambdaDB and its managed embedding provider. A LambdaDB account and inference usage are required. Disable pauses use; it does not delete remote data.

Connects directly to LambdaDB from this browser. Allow this page’s origin in LambdaDB CORS settings. No SillyTavern proxy setting or restart is needed.

Opt in once per story. Native branches reuse committed memory in isolated LambdaDB branches. Initial indexing consumes managed embedding usage; earlier collections remain until all-owned cleanup. This is not a chat rollback control.

Stop generation if the final host prompt omits or changes prepared memory or verifiable recent messages. Turn off to proceed with a warning. Custom macros and continuation prefixes may be unverifiable.

Group chats, files, tool messages, Data Bank, and World Info are excluded. Turn off other chat vectorization extensions. The first version supports one active SillyMemory tab per browser profile.

Renaming keeps memory. Native chat deletion does not remove remote memory: use the delete buttons here. Separate devices must not write to the same memory simultaneously.
