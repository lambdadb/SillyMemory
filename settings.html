Remote data

These actions delete remote memory and keep local chat files. Native chat deletion does not remove remote memory. All-owned cleanup removes every story's memory, including checkpoints.

How memory works

Each story has its own collection. Native branches reuse committed memory in isolated LambdaDB branches. Completed eligible messages are indexed when they leave the recent-five window, keeping adjacent input/reply pairs together. Initial indexing consumes managed embedding usage.

Search uses only the current eligible message; recent dialogue stays in the prompt. The model answers naturally and receives guidance for unclear context and missing evidence. SillyMemory does not force a response format or accumulate unresolved requests.

Group chats, files, tool messages, Data Bank, and World Info are excluded. Renaming keeps memory. Separate devices must not write to the same memory simultaneously.
